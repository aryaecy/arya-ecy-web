# ARYA ECY Web V3.0 Final

Bu paket, GitHub'dan klonlanan gerçek arya-ecy-web kaynak kodu üzerinde hazırlanmıştır.

- Ana ekran görseli: Entegre çevre yönetimini anlatan, saha uzmanları + sanayi tesisi + su + çevresel izleme temalı onaylı görsel.
- Masaüstü: %100 tarayıcı görünümünde tek viewport düzeni için 100dvh grid.
- Footer: Büyük yeşil blok kaldırıldı; açık kurumsal navigasyon + ince koyu yeşil hızlı bağlantı satırı.
- Sağ üst: aryaECY ve aryaAKADEMİ girişleri.
- Ana kartlar: Duyurular, Bizden Haberler, Önemli — tamamı tıklanabilir.
- Alt menü: Hakkımızda, Hizmetler, Kütüphane, Mevzuat, İletişim, ARYA AI.
- Hızlı bağlantılar: ARYA, CSB, UCBS, CMO, LinkedIn.
- Hizmet sayfaları: ortak profesyonel şablon, Ana Sayfaya Dön, ayrı hizmet görseli, çalışma çıktıları ve detaylı makale bölümleri.
- Çevre Yönetimi ve Atık Yönetimi: kapsamlı profesyonel içerik korunmuş ve ortak şablonda gösterilir.

Build notu: Kaynak proje, kullanıcı bilgisayarında `npm install` + `npm run build` ile V2.9.2 tabanında başarıyla build edilmiştir. Bu final revizyonda TypeScript bileşen yapısı değiştirilmemiş; ağırlıklı olarak Hero/Footer/CSS ve yerel hero görseli güncellenmiştir. Bu çalışma ortamında npm bağımlılıkları kurulamamıştır; kullanıcı tarafında yeniden `npm run build` kontrolü önerilir.
