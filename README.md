# ARYA ECY Kurumsal Web Sitesi

Bu sürüm, ARYA ECY'yi yazılım şirketi yerine entegre çevre yönetimi firması kimliğiyle konumlandırır.

## Hizmetler
Çevre Yönetimi, ÇED Yönetimi, Atıksu Yönetimi, Atık Yönetimi, TMGD, KDU, ESG, Karbon Ayak İzi, Su Ayak İzi, Su Verimliliği ve Enerji Yönetimi.

## Site yönetimi
`/yonetim` sayfası Supabase Auth + RLS ile korunur. Yönetimden yayınlanan makaleler Kütüphane'ye, duyurular alt banda, reklamlar ana ekrandaki Güncel alanına gelir. Kurulum için `CMS_KURULUM.md` dosyasını izleyin.
